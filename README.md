# 💳 Credit Card Financial Dashboard

## 📌 Project Overview
This project is an interactive Power BI dashboard that analyzes credit card financial data to provide business insights into revenue, transactions, customer behavior, and card performance.

## 🛠️ Tools & Technologies
- Power BI
- PostgreSQL
- Power Query
- DAX

## 📊 Dashboard Features
- Revenue Analysis
- Transaction Analysis
- Customer Demographics
- Card Category Performance
- Weekly Performance Tracking
- Interactive Filters & Slicers

## 📈 Key Insights
- Revenue and transaction trends by quarter
- Revenue by age, income, education, and occupation
- Card category comparison (Blue, Silver, Gold, Platinum)
- State-wise revenue analysis
- Customer acquisition and interest analysis
